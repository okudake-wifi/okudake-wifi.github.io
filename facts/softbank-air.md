- 引っ越し先が5Gエリア外でも、提供エリア内なら4Gで使える

## ランプの意味と対処（公式FAQ、確認日 2026-11-02）
- 出典: よくあるご質問「Airターミナルのランプが正常に点灯しない場合の対応方法」 https://www.softbank.jp/support/faq/view/18969 ／「Wi-Fiでインターネットにつながらなくなった場合の対応方法」 https://www.softbank.jp/support/faq/view/176000
- 共通: 電源の入れ直し・SIMカードの抜き挿しで改善する可能性がある。表に当てはまらない時は電源アダプタを抜き、差し直す
- **Airターミナル5／6**のランプは5つ: Status／5G/4G／SIM／Wi-Fi／Power。正常なら電源を入れてしばらくすると5つすべて点灯
  - 正常: Status 緑点灯、5G/4G 青点灯か緑点灯（公式注記: 青は5G、緑は4G接続時）、SIM 緑点灯、Wi-Fi 青点灯か緑点灯（青はAirターミナル6のみ。メッシュWi-Fi機器が正常に接続された時）、Power 緑点灯
  - Status 緑点滅＋Power 赤点灯 = ファーム読み込み中。数分待つ。**PowerとStatusが緑点灯するまではインターネットは使えない**
  - Status 緑点滅 = 起動中、待つ／Status 消灯 = インターネットに接続できなかった → 電源アダプタを抜き差し
  - 5G/4G 青点滅・緑点滅 = 電波の入りが悪く接続しづらい → 電波の良い場所へ移動、電源アダプタを抜き差し
  - 5G/4G 赤点灯 = 圏外 → 電波の良い場所へ移動し、電源アダプタを抜いた状態で底面のSIMカードを抜き挿し（金属面に指紋をつけない）
  - 5G/4G 消灯 = 正常に作動しなかった → 電源アダプタを抜き差し
  - SIM 赤点灯・消灯 = SIMカードを認識できない → SIMを抜き挿し、電源アダプタを抜き差し
  - Wi-Fi 緑点滅 = WPS（簡単自動設定）起動中、待つ／Wi-Fi 消灯 = Wi-Fi機能が無効（有線だけなら問題なし。有効にするには初期化で改善する場合あり）
  - Power 赤点灯 = 機器故障の可能性 → 連絡先窓口へ（ただしStatus緑点滅と同時なら読み込み中なので数分待つ）
- 旧機種 Airターミナル2／3／4／4 NEXT: 5G/4Gの代わりに「LTE」ランプ。正常なら5つすべて緑点灯。意味はほぼ同じ（LTE 緑点滅=電波が弱い、赤点灯=圏外）
- 設置場所（同FAQ）: 窓際で30cm〜80cmの高さが適している。直射日光を避ける。棚の中や水槽の近くは避ける
- Wi-Fi設定（FAQ 176000）: Airターミナル6は3つのSSIDのうち「xxxxxx02-5G」に設定（「xxxxxx03-2G」を使うならバンドステアリング機能をオフ）。Airターミナル5以前は2つのSSID
- 解決しない時: 有人チャット（オペレーター対応 10:00〜19:00、年中無休。手続きにはログインが必要）
